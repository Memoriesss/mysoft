Logistic Map 与稳定岛

一维 Logistic 映射 xn+1 = r·xn(1 − xn) 是最简单的混沌系统之一。 当 r 缓慢增加时，x 的长期行为会从稳定的不动点出发， 经历 周期倍增（1 → 2 → 4 → 8 → 16…）， 最终在 r ≈ 3.5699 后坠入混沌海——但在混沌中又藏着无数狭窄的稳定岛， 比如 r ≈ 3.83 处著名的 周期 3 窗口。

稳定岛（周期窗口）

混沌中暗藏无数周期窗口，最著名的是 r ≈ 3.828 的周期 3 窗口。 按 Sharkovsky 定理：出现周期 3 即意味着存在所有周期，混沌的"完整诞生"即从此开始。

真实稳定岛：点击"隐藏/显示稳定岛"切换—— 蓝色背景条标出每个窗口的 r 范围， 金/绿色横线标出该周期对应的 N 个稳定 x 值（n = 周期数）。 这些不是动态光点，而是 Logistic Map 在该 r 区间的真实稳定轨道。

怎么看图

横轴是参数 r，纵轴是状态 x。
抛掉初始瞬态后，每个 r 对应一组（理论上）无穷多个 x。
这些 x 在分岔图上形成"点云"：点越密越像条带，越稀就是周期解。
